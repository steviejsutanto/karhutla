# Current rehearsal settings

This settings file was captured from the running performance for karhutla 1.1.0. It includes the Main mixer, texture controls, performance and ending timings, ground response, rain strength and program notes.

In Operator, open **Setup → Settings file → Import settings** and select **current-performance.json** from this folder. The file is also included in each platform's release download. Import replaces those settings while keeping scene position and landscape progress.

Wi-Fi name and password are blank in this shared copy. Enter the venue's Wi-Fi details in Setup after importing. The repository is public; keep private exports and full performance saves outside Git.
