karhutla 1.0.1 reorganizes the project and simplifies its front page. Application code is in `app/`, automated checks in `tests/`, and detailed guides in `docs/`. Existing operator, projection, audience and settings-transfer behavior is retained.

Download **karhutla-1.0.1-windows-x64.zip**, extract it completely to a local folder, then double-click **Start-Karhutla.cmd**. The runtime, dependencies, recordings, visuals and a satellite snapshot are included. The performance works offline after download; fetching a new snapshot needs internet.

Use **Operator → Setup → Settings file** to export settings from the previous computer/version and import them into this one. Private settings and running performance saves are not included in the download.

See **docs/windows.md** inside the download for projector, audio and Wi-Fi instructions. Keep the launcher console open; Ctrl+C stops the server. Keep the previous rehearsed release available.

Automated Windows checks exercise the bundled runtime, pages, recordings, QR generation and settings transfer. Rehearse on the actual laptop with the projector, PA, router and phones before an event.
