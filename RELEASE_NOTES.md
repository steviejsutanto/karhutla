karhutla is a local participatory performance for a projection, Main audio and audience phones.

Download the **windows-x64.zip** asset, extract it completely to a local folder, then double-click **Start-Karhutla.cmd**. Node.js, dependencies, sounds, visuals and a satellite snapshot are included. The performance works offline after download; fetching a new snapshot needs internet.

Use **Operator → Setup → Settings file** to export settings from the previous computer/version and import them into this one. Settings files and running performance saves are private local files and are not included in the download. Start Main audio again on the destination computer and check the selected audio output.

See **WINDOWS.md** inside the download for projector, audio, Wi-Fi and update instructions. Keep the launcher console open; Ctrl+C stops the server. Keep the previous rehearsed release as a fallback.

Automated Windows checks exercise the bundled runtime and local server. A rehearsal with the actual Lenovo, router, projector, PA and phones is still needed before an event.
